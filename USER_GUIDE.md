# User Guide

Цей посібник допоможе розпочати роботу з демонстраційною системою документації.

## Початок роботи
1. Відкрийте репозиторій.
2. Ознайомтеся з файлами документації.
3. Перейдіть до розділу, який вам потрібен:
   - загальний опис — README.md
   - інсталяція — SETUP_GUIDE.md
   - технічна частина — API_OVERVIEW.md

## Основні можливості
- Перегляд різних типів документації
- Робота з прикладами API
- Вивчення структури проєкту

## FAQ

**1. Чи потрібно встановлювати програму?**  
Ні, це демонстраційний проєкт, доступний онлайн.

**2. Чи можна редагувати файли?**  
Так, якщо у вас є права доступу на GitHub.

**3. Це реальний проєкт чи приклад?**  
Це приклад для навчання документуванню.

**4. Чи можна додавати свої файли?**  
Так, за необхідності можна розширювати документацію.
