# Changelog

Всі значні зміни проєкту документуються тут.

## [1.0.0] - 2025-03-01
- Створено базовий функціонал входу користувача
- Додано сторінку "Мій профіль"
- Додано базовий GET /tasks

## [1.1.0] - 2025-05-15
- Додано можливість створювати нові завдання (POST /tasks)
- Виправлено помилки відображення статусу завдань
- Додано дату створення завдання

## [1.2.0] - 2025-07-20
- Додано отримання деталей конкретного завдання (GET /tasks/{id})
- Поліпшено обробку помилок API
- Оптимізовано відповіді сервера

## [1.3.0] - 2025-10-10
- Додано сортування завдань за датою створення
- Оновлено документацію API
- Виправлено дрібні баги у фронтенді та бекенді
