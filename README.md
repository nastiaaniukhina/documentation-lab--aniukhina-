# Documentation Lab — Система демонстрації типів документації

Цей проєкт — навчальна система, створена для демонстрації основних видів технічної документації.  
Вона допомагає студентам зрозуміти, як правильно оформлювати README, користувацькі інструкції, інсталяційні довідники та технічні API-описи.

## Яку проблему вирішує система?
- Дозволяє швидко створювати структуровану документацію
- Слугує шаблоном для реальних проєктів
- Допомагає навчитися базових підходів до документування ПЗ

## Основні функції
- Приклад користувацької документації
- Приклад інсталяційного довідника
- Приклад API-ендпойнтів
- Журнал змін (CHANGELOG)
- Приклади ілюстрацій у папці `/images`

## Для кого цей продукт?
- Студенти ІТ-спеціальностей
- Початківці технічні письменники
- Розробники, які хочуть навчитися писати документацію
