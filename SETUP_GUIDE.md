# Setup Guide

Це інструкція з інсталяції та запуску демонстраційної системи документації.

## Необхідні інструменти
- Будь-який браузер (Chrome, Firefox, Edge)
- Доступ до GitHub

## Встановлення
1. Відкрийте веббраузер.
2. Перейдіть на сторінку репозиторію.
3. За потреби створіть форк або клон репозиторію: https://github.com/nastiaaniukhina/documentation-lab--aniukhina-

## Запуск
Оскільки система складається з документації, запуск не потрібен.  
Ви просто відкриваєте необхідний `.md` файл.

## Перевірка роботи
Перевірте, що:
- усі файли зберігаються в репозиторії;
- текст читається коректно;
- посилання між файлами працюють (якщо ви їх додаєте).

Якщо всі файли відкриваються — система працює правильно.
